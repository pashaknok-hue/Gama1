name: NO RULES interface direction
description: Product UX constraints for future NO RULES interface work.
---

For NO RULES, keep gameplay text-driven rather than dashboard- or Sims-like. The pixel-art scene is compact; character stats and time controls stay secondary; the chronological life journal is the main surface. Important events stop time and offer exactly four meaningful choices with distinct consequences. Design mobile-first with readable text and avoid excess cards.

Keep the interface ready for future cutscenes and minigames, but do not build those systems until requested. When changing the visual hierarchy, preserve existing life logic, random generation, actions, and saves.

**Why:** The user supplied this as the product's specific UI direction for NO RULES.

**How to apply:** Use this direction for future NO RULES UI changes; add new gameplay systems only when the user asks for them.
