# Обновление открытых данных мира

Приложение использует только сохранённые JSON; при игре нет запросов к GeoNames,
Faker, Mimesis или Wikidata. Обычная установка проекта не обновляет эти данные.
Атрибуция, лицензии и ограничения — `artifacts/no-rules/data/NOTICE.md`.
Фактическое покрытие — `artifacts/no-rules/data/COVERAGE.md`.

Для намеренного обновления создайте отдельный каталог исходников и Python venv
вне checkout. Установите закреплённые пакеты:

```sh
npm ci --prefix scripts/world-data
python -m pip install -r scripts/world-data/requirements.txt
```

Скачайте с TLS-проверкой в каталог исходников `$WORLD_SOURCES`:

- https://download.geonames.org/export/dump/countryInfo.txt → `countryInfo.txt`
- https://download.geonames.org/export/dump/admin1CodesASCII.txt → `admin1.txt`
- https://download.geonames.org/export/dump/cities500.zip → `cities500.zip`

Экспорт и сборка из корня checkout (переменная `WORLD_SOURCES` — путь к каталогу):

```sh
node scripts/world-data/export-locales.mjs scripts/world-data "$WORLD_SOURCES/faker.json"
python scripts/world-data/export-python-locales.py "$WORLD_SOURCES/python-faker.json"
python scripts/world-data/export-mimesis.py "$WORLD_SOURCES/mimesis.json"
# При первичной сборке словаря нужны корректные данные name-pools.json в checkout.
python scripts/world-data/fetch-russian-names.py "$WORLD_SOURCES"
python scripts/world-data/import.py --sources "$WORLD_SOURCES" --packages scripts/world-data
```

Импортер воспроизводит географию и наборы имён из файлов; результаты и новый
manifest должны пройти review и тесты. SHA-256 старых входных файлов находятся
в manifest; обновление живых GeoNames/Wikidata намеренно может изменить их.
Пакеты фиксированы lockfile/requirements. Импортер не отключает TLS, не подменяет
контрольные суммы и не записывает данные в старые сохранения.

Wikidata запрашивается точными значениями и языками, не общим поиском похожих
имён. Кэш ключуется содержимым запроса. Таймауты и ошибки сохраняются как
`unavailable`; неподтверждённые пакеты не используются. Совпадения с несколькими
русскими формами исключаются. Подлинность русского написания не выводится из
общего латинско-кириллического правила. Импортированный словарь неполон;
обновление может расширить его, но не переименовывает сохранённых персонажей.

При добавлении локали нужно проверить половые списки, реальные правила порядка
имени и наследования, наличие надёжного соответствия гендерных форм фамилии.
Массивы мужских и женских фамилий источников не считаются параллельными.
Сопоставления форм выводятся только при наличии единственной подходящей формы
в исходном женском списке; никакое новое русское окончание не переносится на
другой язык. Для польского набора отдельно применяется польское правило
`-ski/-ska`, `-cki/-cka`, `-dzki/-dzka`: https://en.wikipedia.org/wiki/Polish_names.
Для исландского — исходный словарь засвидетельствованных родительных форм;
неподтверждённые формы не угадываются. Испанские и португальские две семейные
линии — поддержанные варианты, а не предположение обо всех семьях страны.

География: 193 члена ООН плюс дополнительные территории; у страны без поселений
генератор выбрасывает явную ошибку вместо скрытого выбора другой страны.
Население GeoNames используется как необязательный вес страны, не как число
рождений. Стандартный выбор стран равновероятен. Населённые пункты выбираются
равновероятно из снимка; это не имитация реальной мировой рождаемости.
