# Реальное покрытие генерации мира

География: 193 государства-члена ООН; 246 стран/территорий с поселениями из 250 записей. Наборы имён: 99 стран/территорий, в том числе 97 из 193 членов ООН. Для остальных используется маркированный языковой либо резервный набор (см. дополнение выше). Русская запись берётся только из однозначного источника; при неполном соответствии сохраняется исходное имя целиком.

Источник географии: GeoNames countryInfo, admin1CodesASCII и cities500. Страны и русские названия: world-countries 5.1.0; членство ООН исправлено для Ватикана (наблюдатель). Имена: JS Faker 10.1.0, Python Faker 37.12.0 и Mimesis 18.0.0, таблицы ниже учитывают только собственные данные локали; новый языковой/резервный поиск в эти числа не входит. Русские написания: однозначные точные соответствия Wikidata, иначе исходная запись.

Регионы и поселения выбираются связанной записью GeoNames, а не склеиваются независимо. Если административный регион отсутствует, это отмечается явно. Тип размера определяется населением: мегаполис ≥ 10 млн, город ≥ 100 тыс., небольшой город ≥ 10 тыс., малый населённый пункт < 10 тыс. Это не юридическая классификация «город/деревня». В базе присутствуют реальные малые поселения; полная база всех деревень мира не заявляется.

Faker — поддерживаемый набор тестовых имён, не реестр населения. Наличие локали не означает покрытие всех этносов страны. Связи с общими языковыми наборами заданы явно и не являются демографическими долями. Для отсутствующего набора выводится «Имя не указано», без случайного английского или русского имени.
