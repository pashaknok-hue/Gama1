# Проверка глобального генератора

Снимок и код проверены 2026-11-02. Числа ниже получены из настоящего генератора,
а не из списка подготовленных примеров.

| Проверка | Результат |
|---|---|
| География | 193 члена ООН; 250 записей стран и территорий; 246 с подходящими поселениями |
| Поселения | 12 778 связанных записей GeoNames; 2746 с населением от 1 до 999 |
| Наборы имён | 99 стран/территорий; 97 членов ООН и две дополнительные территории |
| Пробелы имён | 96 членов ООН без подходящего набора; явное «Имя не указано» |
| Русские написания | 11 606 однозначных словарных соответствий Wikidata; исходная запись, если полная форма неизвестна |
| Node-тесты | 203 прошли, 0 упали; каждый член ООН проверен отдельно |
| 10 000 случайных рождений | 193 страны, 5752 разных поселения, 4972 разных имени, 4070 разных составных значений фамилии/второй части имени |
| Рождения с именами / без набора | 5001 / 4999 при равновероятном выборе стран |
| Сохранения | Все 10 000 рождений сохранены/загружены с точным сравнением героя, семьи, места и истории |
| Браузер Chromium | 1200 случайных рождений: 193 страны, 593 разных имени, оба пола; 607 без набора имён |
| UI | 14 стран обоих полов, настройки распределения, источники, родственники и текст нового события; сохранение/загрузка |
| Таймер | Автостарт, пауза/остаток шага, 1×/4×, день рождения и реальный 10-секундный тик прошли |
| Мобильный UI | 13 размеров, 120 событий в журнале, диалоги и сохранения прошли |
| TypeScript / сборка | Все workspace-пакеты прошли |
| Повторяемость импорта | JSON-файлы воспроизведены побайтно из сохранённых исходников |

Семейные тесты проверяют половые колонки источника для имён и фамилий,
гендерные варианты русских фамилий, две семейные линии в испанском/португальском
вариантах, порядок «фамилия — имя» и исландские патронимы.
Старые имена (даже некорректные), многословные имена родственников и журнал
сохраняются без нормализации. Наличие тестов не означает исчерпывающей
лингвистической верификации всех записей внешних наборов.

GeoNames в этом снимке не даёт административный регион первого уровня для
Сингапура; игра сохраняет реальное поселение и явный пропуск региона.
В Wikidata 30 пакетов запроса были недоступны и не используются как проверенные
данные. Реальный Safari/iPhone здесь недоступен; геометрия безопасных зон
проверена искусственными отступами в Chromium.
