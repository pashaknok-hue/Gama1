# Проверка мобильного интерфейса NO RULES

Из корня репозитория, с Node.js 24 и pnpm 10:

```sh
PORT=5173 BASE_PATH=/ pnpm run build
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/no-rules run dev
```

Автоматическая браузерная проверка использует Python 3, пакет `playwright` и Chromium.
Их можно установить в отдельное виртуальное окружение вне checkout; зависимости
игры менять не требуется. Если системного `chromium` нет, установите браузер
через `python -m playwright install chromium`.
В другом терминале:

```sh
python artifacts/no-rules/tests/mobile_smoke.py
```

Для другого адреса задайте `NO_RULES_TEST_URL`. Скрипт создаёт изолированный
браузерный контекст, не использует сохранения вашего обычного браузера и сохраняет
снимки экрана во временную директорию, путь к которой выводится в конце.

Проверки: 13 размеров от 320×480 до 1440×900; отсутствие прокрутки документа и
выхода основных блоков за экран; кнопки высотой не менее 44 px; прокрутка журнала
из 120 событий; новые события сверху без перестановки массива в сохранении;
продвижение месяца, скорость, пауза, сохранение и загрузка, действия, отмена новой
жизни и доступность всех четырёх вариантов решения в портретном и альбомном режимах.
Длинная история и окно выбора проверяются на тестовых данных в localStorage.
Дополнительно проверяется геометрия с искусственными отступами безопасной зоны.
Это не эмуляция поведения Safari или аппаратного выреза экрана.

На настоящем iPhone в Safari дополнительно проверьте:

1. Начните жизнь или загрузите существующую. Имя, семья и прогресс должны сохраниться.
2. Сверните и разверните адресную/нижнюю панель Safari, поверните телефон.
   Кнопки должны оставаться видимыми над индикатором Home, контент — вне выреза.
3. Прокрутите длинный дневник: сцена, показатели и управление должны остаться на месте.
4. Откройте действия и важное решение. В небольшом окне прокручивается сам диалог,
   все варианты доступны; фоновая страница остаётся неподвижной.
5. Проверьте масштабирование жестом: viewport больше не запрещает увеличение.

На экране нового рождения прокручивается внутренняя область анкеты.
В активной игре прокручивается только дневник, а при открытом диалоге — его содержимое.
Логика симуляции, формат сохранений и генерация персонажей не изменены.

## Таймер и продвижение жизни

```sh
python artifacts/no-rules/tests/timer_smoke.py
```

Тест запускает настоящую игру в Chromium. Управляемые часы Playwright проверяют
автостарт, продвижение даты и появление событий, полную остановку на паузе,
возобновление с остатком месяца, смену скорости посреди шага и соотношение 1×/4×.
Также проверяются сохранение на паузе, загрузка без двойного таймера, двенадцать
месяцев до первого дня рождения, обновление возраста и вехи, остановка перед
важным решением и продолжение после выбора.
Отдельный браузерный контекст без подмены времени ждёт реальный первый тик
и проверяет паузу. Новая игра и загрузка запускают время автоматически;
неразрешённый выбор останавливает его до решения и нажатия продолжения.
Один игровой месяц занимает 10 секунд на 1× и 2,5 секунды на 4×.
Закрытая игра не рассчитывает офлайн-прогресс; формат существующих сохранений
не меняется. Остаток шага сохраняется при паузе и смене скорости в текущем сеансе.

## Глобальный мир, имена и сохранения

```sh
pnpm --filter @workspace/scripts exec node --import tsx ../artifacts/no-rules/tests/names.test.ts
python artifacts/no-rules/tests/names_smoke.py
```

Node-тесты проверяют 193 государства ООН по отдельности, **10 000 случайных
рождений** через настоящий генератор, реальные связи страны/региона/поселения,
разнообразие имён и полов, половые варианты фамилий, местные традиции, выбор по
населению, дополнительные территории, старые и новые сохранения.
Браузерный тест вызывает тот же production-модуль: **1200 случайных рождений**,
проверка сохранения и загрузки каждого, затем экран игры, родственников и события
для 14 стран обоих полов. Примеры не заменяют случайную генерацию.

География всех 193 членов ООН проверена по источнику. Включение дополнительных
территорий и вес по населению можно выбрать на экране рождения. По умолчанию
193 страны имеют равные шансы; поселения равновероятны внутри снимка страны.
Это не имитация реальной глобальной рождаемости.

Полное покрытие, включая отсутствие наборов имён: [COVERAGE.md](../data/COVERAGE.md).
Атрибуция и ограничения: [NOTICE.md](../data/NOTICE.md).
Обновление источников: [scripts/world-data/README.md](../../../scripts/world-data/README.md).
Географический снимок содержит реальные поселения разных размеров, но не все
деревни мира. Политико-географические изменения по историческим годам не моделируются.

Нельзя считать наличие локали полным охватом культур страны. Если подходящего
набора нет, выводится «Имя не указано», и русские события используют слово
«ребёнок». Никакого автоматического отката к русскому/английскому имени нет.
Русские написания иностранных имён используются только при однозначном полном
соответствии Wikidata; иначе исходное имя сохраняется целиком. Склонение неизвестных
форм не выполняется, предложения используют именительный падеж.

В сохранении авторитетно поле `name`, а данные происхождения имени и места рождения
добавлены необязательно. Загрузка не меняет старые имена, фамилии родственников,
старые географические строки или исторические записи. Изменение словаря после
обновления приложения не переименовывает уже рождённых персонажей.

## Возрастные события и решения

```sh
pnpm --filter @workspace/scripts exec node --import tsx ../artifacts/no-rules/tests/events.test.ts
python artifacts/no-rules/tests/events_smoke.py
```

`advanceTime` моделирует течение жизни помесячно. Это API таймера и кнопок
«+ месяц / + год»; оно не выбирает действие за игрока. `advance` принимает только
доступное занятие самого персонажа: до трёх лет список пуст, затем учитываются
возраст и энергия. Неизвестные/недоступные действия не меняют состояние.

Новые записи различают жизненные события, занятия персонажа, решения и вехи.
Для каждого сохраняются участник, объект, контекст и идентификатор шаблона.
В младенчестве действуют взрослые либо окружающий мир. Если родителя нет в данных,
событие не придумывает ему имя: используется близкий взрослый без вымышленной родственной связи.
Занятия дошкольников и прогулки детей описываются с поддержкой взрослого.

Решения разделены на 3–5, 6–12, 13–17 и 18+ лет, предлагают четыре посильных
варианта. Они не появляются у младенца и не повторяются ежемесячно: между
решениями минимум четыре месяца, тот же сценарий — не ранее восьми месяцев.
Автоматический шаблон не повторяется среди последних трёх жизненных событий;
явное повторное занятие игрока разрешено. Выбор останавливает также перемотку
года на первом требующем ответа месяце. После решения время можно продолжить.

Тесты проверяют младенчество, детство, подростковый и взрослый возраст, ограничения
действий по энергии, родителя как участника заботы, отсутствие родителя, календарные
границы, тридцать лет развития, интервалы повторений и сохранение/загрузку.
Браузерный тест проходит возраста 0, 4, 8, 15, 25, проверяет меню, журнал, четыре
варианта, результат и продолжение таймера. Снимки экрана сохраняются во временный каталог.

Старые имена, события и прогресс не перезаписываются. Старый школьный выбор,
неподходящий текущему возрасту, не блокирует жизнь и не может дать эффекты.
Старые повелительные записи младенчества без участника и контекста показываются
как архивные с пояснением, не выдаются за решения младенца; исходная запись остаётся в сохранении.

Для ручной проверки начните новую жизнь: время должно само добавлять события
заботы/окружения, а кнопка занятий — показывать пояснение о младенчестве.
После трёх лет появятся простые занятия. На старших этапах проверьте доступность
по возрасту и то, что взрослым не предлагается школьный сценарий.
