## Причина повторов в опубликованном коде

На main таймер вызывает `advance(..., automaticAction(current), 1)`.
`automaticAction` выбирает `cuddle` для персонажа младше трёх лет, если энергии
не меньше 28. Поэтому обычный тик каждый раз записывает действие «Обнять ребёнка».
Защиты от такого повтора и разделения автоматической жизни/действий в этом коде нет.

В итоговом движке таймер вызывает отдельный `advanceTime`. Забота — событие взрослого,
а не решение младенца. Повседневные шаблоны имеют интервал шесть игровых месяцев
по сохранённой истории; контакты NPC и загрузка не сбрасывают этот интервал.

## Воспроизведение старого бага и проверка исправления

Сценарий: Вадим Янюк, Киев, рождение **3 декабря 2000 года**.
Киев взят из текущего географического снимка (GeoNames ID 703448).
Для браузера и логики используется одна сверяемая фикстура старого сохранения без
нового слоя симуляции. Начальная дата — 2000-12-03, возраст — 0.

Один и тот же Playwright-тест запускался против двух серверов:

1. Неизменённый main `a543ce0` в отдельном detached worktree, порт 5174.
   Получено:

   ```text
   2001-01-03 — Обнять ребёнка
   2001-02-03 — Обнять ребёнка
   2001-03-03 — Обнять ребёнка
   Expected length: 0; Received length: 3
   ```

   Тест ожидаемо падает именно на повторении, после проверки дат и отрисовки записей.
2. Итоговая ветка, порт 5173. Тот же тест входит в полный браузерный набор.
   Требуется три разных шаблона, максимум одно событие `care-embrace`, отсутствие
   старых действий и решений младенца. После каждого месяца выполняется загрузка.
   Финальный запуск прошёл и получил:

   ```text
   2001-01-03 — После кормления (care-feeding)
   2001-02-03 — Тихая песня (care-song)
   2001-03-03 — Тепло объятий (care-embrace)
   ```

Тест логики дополнительно использует постоянный RNG `() => 0`: даже постоянный выбор
первого доступного шаблона не вызывает ежемесячные повторы. За год проверяется
шестимесячный интервал и первый день рождения строго 2001-12-03.

- 250 отдельных тестов логики, включая 3 новых регрессионных теста.
- 2 теста воспроизведения/массовой симуляции: **1000 жизней до 85 лет**, **193 страны**,
  **1 020 000 месяцев**, **1 187 750 записей**, **150 320 решений**, **6000 сохранений**,
  **0 ошибок инвариантов**. Время массового прогона: 144,068 секунды.
- TypeScript и полная сборка workspace выполнены на итоговой ветке.
- Все 4 сценария полного Playwright-набора прошли за 1,9 минуты: конкретная регрессия Киева,
  таймер/пауза/4× и мобильная геометрия, сохранение полной жизни/выборы без раскрытия
  неизвестных результатов, проход реальными кнопками от рождения до 85 лет.
  В длинном ручном сценарии виртуальные часы фиксируются, чтобы автоматический тик
  не конкурировал с нажатием кнопок; проверка автоматического таймера остаётся
  отдельным сценарием. Первый полный запуск был нестабилен, финальный повтор
  после сборки с зафиксированными часами прошёл целиком.
