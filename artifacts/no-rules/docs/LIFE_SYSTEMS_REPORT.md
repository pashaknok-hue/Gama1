## Pixelbolt: реальная изолированная интеграция

Исследован [Pixelbolt](https://github.com/skulitom/Pixelbolt); установлен локальный
MIT-пакет **0.10.0**. Скрипт действительно вызывает его CLI и экспортирует
оригинальный рецепт `art/observer.json` в PNG/атлас. Это детерминированный
растеризатор, а не сервис, самостоятельно придумывающий анатомию и позы.
Персонаж, палитра и движения написаны в проекте. Платные API и внешние
генеративные сервисы не подключались.

Отдельная React-страница `/prototype`: idle (2 кадра), walk (4), sit (2), sleep (2),
пауза и целочисленный масштаб 2×/4×/6×/8×. PNG 24×32, опора y=30 с учётом двух
прозрачных строк под ней. Тест декодирует готовые PNG: проверяет опору и минимум
два действительно различных изображения на анимацию, а не только смену имени кадра.
Страница не читает/не меняет сохранение игры и не заменяет основную сцену.
Это небольшой технический прототип; богатая библиотека движений и вариации NPC
остаются дальнейшей художественной работой.

Из корня репозитория:

```sh
pnpm install --frozen-lockfile
pnpm --filter @workspace/no-rules art:prototype
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/no-rules run dev
```

Открыть `http://localhost:5173/` для игры и
`http://localhost:5173/prototype` для прототипа. При другом `BASE_PATH` добавить
его префикс. В прототипе переключить четыре анимации, масштаб и паузу; проверить
320 px и альбомный экран. В игре проверить продолжение после решения, ручную
паузу, новый школьный путь и «Историю жизни → Деньги».
